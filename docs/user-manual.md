## 一、系统概述

Medicompass 是一个跨国远程二次诊疗意见咨询服务平台。客户提交申请后,平台管理员指派服务机构整理结构化病历,再指派专家医生出具诊疗意见,最终由服务机构生成双语报告,管理员终审后交付客户。

系统支持中英文双语,所有页面路径以 `/zh` 或 `/en` 开头,可在语言切换按钮处切换。

| 角色 | 登录入口 | 主功能区 |
|---|---|---|
| 客户(患者) | `/{lang}/login` | `/{lang}/account/applications` |
| 服务机构(供应商) | `/{lang}/login` | `/{lang}/account/assigned` |
| 专家医生 | `/{lang}/login` | `/{lang}/account/assigned` |
| 平台管理员 | `/{lang}/admin/login` | `/{lang}/admin` |

## 二、客户(患者)操作指南

### 2.1 注册账号

1. 访问首页,点击「注册」进入注册页面 `/{lang}/register/patient`。
2. 填写姓名、手机号、邮箱等信息,提交后完成注册。
3. 若仅快速发起咨询,可使用快捷注册入口 `/{lang}/register/quick`。

### 2.2 登录系统

1. 访问 `/{lang}/login`。
2. 输入手机号(或邮箱)与密码,点击登录。
3. 登录成功后自动进入「我的申请」页面。

### 2.3 发起二次诊疗申请

1. 登录后,在「我的申请」页面点击「二次诊疗申请」按钮,或直接访问 `/{lang}/second-opinion/apply-logged-in`。
2. 填写申请信息:
   - 需求类型(如二次诊疗、就医安排等)
   - 目标国家/地区
   - 病情描述(详细说明病史、症状、既往诊疗等)
   - 上传病历附件(支持图片、PDF 等)
3. 点击提交,申请进入「待初审」状态。

### 2.4 查看我的申请

1. 登录后进入 `/{lang}/account/applications`。
2. 列表显示所有申请,包含需求类型、服务名称、国家、当前状态、提交时间。
3. 点击「查看」进入申请详情页 `/{lang}/account/applications/{id}`。

### 2.5 补充资料(待补充状态)

当申请状态为「待补充资料」(`PENDING_SUPPLEMENT`)时:

1. 进入申请详情页,页面顶部会出现补充表单。
2. 按提示修改信息或上传补充附件。
3. 点击提交,申请回到「待初审」状态等待管理员复审。

> 注意:仅在「待补充资料」状态下,客户可以编辑申请信息;其他状态下信息为只读。

### 2.6 下载最终报告

当申请状态为「已交付」(`COMPLETED`)时:

1. 进入申请详情页,页面底部出现「最终报告」区块。
2. 点击报告链接可在线预览,或点击「下载」按钮保存到本地。
3. 报告为双语 PDF 格式。

### 2.7 功能模块一览

| 模块 | 路径 | 说明 |
|---|---|---|
| 我的申请 | `/account/applications` | 查看申请列表与状态 |
| 申请详情 | `/account/applications/{id}` | 查看申请信息、附件、最终报告,补充资料 |
| 二次诊疗申请 | `/second-opinion/apply-logged-in` | 发起新申请 |

## 三、服务机构(供应商)操作指南

服务机构负责接收平台指派的申请,整理结构化病历并上传最终报告。

### 3.1 注册入驻

1. 访问 `/{lang}/register/provider`。
2. 填写机构名称、资质证明、联系方式等资料,上传相关证件。
3. 提交后等待管理员审核。审核状态为「草稿」或「已驳回」时可继续编辑。

### 3.2 登录系统

1. 访问 `/{lang}/login`,使用机构账号登录。
2. 登录成功后进入「我的任务」页面。

### 3.3 查看我的任务

1. 登录后进入 `/{lang}/account/assigned`。
2. 列表显示所有指派给本机构的申请,包含需求类型、服务、客户姓名、国家、状态、时间。
3. 点击「查看」进入任务详情页 `/{lang}/account/assigned/{id}`。

### 3.4 处理申请(机构工作台)

在任务详情页,「机构工作台」区域提供以下操作:

#### 步骤 1:接受或拒绝申请

- **接受申请**:点击「接受」按钮,申请进入「服务商处理中」状态。
- **拒绝申请**:点击「拒绝」,填写拒绝理由后提交,申请回退给管理员处理。

#### 步骤 2:提交结构化病历

接受申请后,填写以下字段并提交(所有字段为必填):

- 病情摘要(Medical Summary)
- 化验与检查结果(Lab & Test Results)
- 当前治疗方案(Current Treatment)
- 咨询问题 1 / 问题 2 / 问题 3

提交后申请进入「待指派医生」状态,等待管理员指派医生。

#### 步骤 3:上传最终报告

医生提交诊疗意见后,申请回到机构侧进入「报告翻译中」状态:

1. 上传最终双语 PDF 报告(文件大小不超过 50MB)。
2. 填写医生解答的中文翻译(3 项)。
3. 点击提交,申请进入「平台终审中」状态。

### 3.5 功能模块一览

| 模块 | 路径 | 说明 |
|---|---|---|
| 我的任务 | `/account/assigned` | 查看指派给本机构的申请 |
| 任务详情 | `/account/assigned/{id}` | 接受/拒绝申请、结构化病历、上传报告、翻译 |
| 个人资料 | `/account/profile` | 维护机构档案 |

## 四、专家医生操作指南

专家医生负责阅读结构化病历,出具专业诊疗意见。

### 4.1 注册入驻

1. 访问 `/{lang}/register/doctor`。
2. 填写姓名、执业资质、所属机构、联系方式等,上传相关证件。
3. 提交后等待管理员审核。审核状态为「草稿」或「已驳回」时可继续编辑。

### 4.2 登录系统

1. 访问 `/{lang}/login`,使用医生账号登录。
2. 登录成功后进入「我的任务」页面。

### 4.3 查看我的任务

1. 登录后进入 `/{lang}/account/assigned`。
2. 列表显示所有指派给本人的申请,包含需求类型、服务、客户姓名、国家、状态、时间。
3. 点击「查看」进入任务详情页 `/{lang}/account/assigned/{id}`。

### 4.4 提交诊疗意见(医生工作台)

在任务详情页,「医生工作台」区域提供以下操作:

1. 阅读客户信息、病情描述与附件病历(只读)。
2. 阅读服务机构提交的结构化病历(病情摘要、化验结果、当前治疗、3 个咨询问题)。
3. 针对 3 个咨询问题,分别填写英文诊疗意见:
   - Answer 1
   - Answer 2
   - Answer 3
4. 三项均填写完成后,点击「提交」。
5. 提交后申请进入「报告翻译中」状态,由服务机构继续处理。

> 提示:可点击「下载附件包」获取客户上传的全部病历文件,便于查阅。

### 4.5 功能模块一览

| 模块 | 路径 | 说明 |
|---|---|---|
| 我的任务 | `/account/assigned` | 查看指派给本人的申请 |
| 任务详情 | `/account/assigned/{id}` | 阅读病历、填写并提交 3 项诊疗意见 |
| 个人资料 | `/account/profile` | 维护医生档案 |

## 五、平台管理员操作指南

管理员独立后台登录,负责申请审核、人员指派、终审质检与注册审核。

### 5.1 登录后台

1. 访问 `/{lang}/admin/login`。
2. 输入管理员用户名与密码,点击登录。
3. 登录成功后进入申请管理列表页 `/{lang}/admin`。
4. 如未登录直接访问后台页面,会自动跳转至登录页。

### 5.2 申请管理(首页)

登录后默认进入申请列表页 `/{lang}/admin`:

- 按需求类型筛选申请(点击顶部标签)。
- 列表显示:客户姓名、需求类型、服务、国家、附件数量、AI 摘要状态、当前状态、提交时间。
- 点击「查看」进入申请详情页 `/{lang}/admin/applications/{id}`。

### 5.3 申请详情与操作

进入申请详情页,可执行以下操作(按申请阶段不同显示对应操作):

#### 状态面板(StatusPanel)

- **初审通过**:将「待初审」申请推进至「待指派」。
- **驳回申请**:将「待初审」申请标记为「已驳回」。
- **要求补充资料**:将申请转为「待补充资料」,客户可编辑并重新提交。

#### 指派面板(AssignPanel)

- **指派服务机构**:选择一个已审核通过的机构,申请进入「服务商处理中」。
- **指派医生**:在机构提交结构化病历后,选择医生,申请进入「专家看诊中」。
- 首次指派时,系统会自动将状态从「待初审」推进到「待指派」再到对应处理状态。

#### 终审面板(FinalReviewPanel)

当申请进入「平台终审中」(`ADMIN_QC`)时:

- **通过终审**:申请变为「已交付」(`COMPLETED`),客户可下载报告。
- **驳回终审**:申请退回「报告翻译中」(`PROVIDER_TRANSLATING`),机构需重新处理。

#### 其他功能

- **AI 摘要面板**:查看 AI 对病历附件的自动摘要结果,状态分为已完成/处理中/失败。
- **处理产物**:查看机构提交的结构化病历、医生解答、中文翻译等。
- **事件时间线**:查看申请全流程的操作记录(谁在何时做了什么)。
- **超级编辑(SupremeEditPanel)**:管理员可直接编辑申请的任意字段。

### 5.4 注册审核

访问 `/{lang}/admin/registrations`:

1. 切换标签页查看「服务机构」或「医生」的注册申请。
2. 可按状态筛选:全部、草稿、待审核、已通过、已驳回。
3. 点击「查看」进入详情页 `/{lang}/admin/registrations/{type}/{id}`,审核通过或驳回。

> 只有审核通过的机构和医生才能被指派处理申请。

### 5.5 询价管理

访问 `/{lang}/admin/inquiries`:

- 查看客户提交的服务询价/咨询信息。
- 列表显示:客户姓名、联系电话、咨询服务、留言内容、提交时间。
- 管理员可据此联系客户并跟进。

### 5.6 修改密码

访问 `/{lang}/admin/password`,输入旧密码与新密码后提交。

### 5.7 功能模块一览

| 模块 | 路径 | 说明 |
|---|---|---|
| 申请管理 | `/admin` | 申请列表,按需求类型筛选 |
| 申请详情 | `/admin/applications/{id}` | 初审、指派、终审、查看全流程 |
| 注册审核 | `/admin/registrations` | 审核机构/医生入驻申请 |
| 询价管理 | `/admin/inquiries` | 查看客户询价信息 |
| 修改密码 | `/admin/password` | 修改管理员登录密码 |

## 六、申请状态流转说明

二次诊疗申请的完整状态流转如下:

```
待初审(PENDING_REVIEW)
    │
    ├─ 管理员驳回 → 已驳回(REJECTED)
    ├─ 管理员要求补料 → 待补充资料(PENDING_SUPPLEMENT)
    │        └─ 客户重新提交 → 待初审(PENDING_REVIEW)
    │
    └─ 管理员指派机构 → 待指派(PENDING_ASSIGN) → 服务商处理中(PROVIDER_PROCESSING)
                  │
                  ├─ 机构拒绝 → 回退管理员
                  └─ 机构提交结构化病历 → 待指派医生(PENDING_DOCTOR_ASSIGN)
                              │
                              └─ 管理员指派医生 → 专家看诊中(DOCTOR_PROCESSING)
                                          │
                                          └─ 医生提交意见 → 报告翻译中(PROVIDER_TRANSLATING)
                                                      │
                                                      └─ 机构上传双语报告 + 翻译 → 平台终审中(ADMIN_QC)
                                                                  │
                                                                  ├─ 管理员通过 → 已交付(COMPLETED)
                                                                  └─ 管理员驳回 → 报告翻译中(PROVIDER_TRANSLATING)
```

### 各角色可操作的状态

| 角色 | 可操作状态 | 操作内容 |
|---|---|---|
| 客户 | `PENDING_SUPPLEMENT` | 补充资料、修改信息、上传附件 |
| 客户 | `COMPLETED` | 下载最终双语报告 |
| 服务机构 | `PROVIDER_PROCESSING` | 接受/拒绝申请、提交结构化病历 |
| 服务机构 | `PROVIDER_TRANSLATING` | 上传最终报告、提交中文翻译 |
| 专家医生 | `DOCTOR_PROCESSING` | 提交 3 项诊疗意见 |
| 管理员 | `PENDING_REVIEW` | 初审通过/驳回/要求补料 |
| 管理员 | `PENDING_ASSIGN` / `PENDING_DOCTOR_ASSIGN` | 指派机构/医生 |
| 管理员 | `ADMIN_QC` | 终审通过/驳回 |
| 管理员 | 所有状态 | 超级编辑、查看事件时间线 |
